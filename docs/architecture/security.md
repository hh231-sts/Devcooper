# Security

- API Key 和 GitHub Token 只通过环境变量或用户输入提供。
- 不在日志中打印 token。
- MVP 阶段不写回 GitHub，只生成草稿。
- GitHub Token 如需持久化，必须加密保存。
- Issue/PR/CI 调查工具只读取固定快照、代码归档与材料；没有文件写入、测试执行、GitHub 评论、分配、关闭、合并或重跑能力。
- 出站材料会发送给项目配置的 LLM；角色只能调用其允许的材料、协作和结论工具，不能再次调用自身分析入口。
- PR head、CI commit 与 attempt 分别绑定，合成合并保留关联。失败 CI 门禁由服务端保留，模型综合不能覆盖。
- 调用失败或未保存响应的中断直接记录并结束受影响任务，不重试、不切换默认代码分支、不生成规则结果冒充调查完成。
